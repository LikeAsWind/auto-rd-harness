# Triage 标签

各技能统一用五个标准 triage 角色来表达状态。下表把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义                         |
| ---------------------------- | ------------------------- | ---------------------------- |
| `needs-triage`               | `needs-triage`            | 需要维护者评估该议题         |
| `needs-info`                 | `needs-info`              | 等待报告者补充更多信息       |
| `ready-for-agent`            | `ready-for-agent`         | 描述完整,可交给 AFK agent   |
| `ready-for-human`            | `ready-for-human`         | 需要人工实现                 |
| `wontfix`                    | `wontfix`                 | 不会处理                     |

当某个技能提到一个角色时(例如「打上 AFK-ready 的 triage 标签」),使用表中对应的 label 字符串。

如果你实际使用的是另一套词汇,直接改右侧那一列即可。
